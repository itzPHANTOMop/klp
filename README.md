# 👻 PHANTOM GAMING - Official Creator Hub & Portal

Welcome to the official **Phantom Gaming** portal repository! This website is built with single-page architecture powered by **Tailwind CSS**, **FontAwesome 6**, and modern GPU-accelerated smooth animations.

---

## ✨ Features

- 🌓 **Dual-Theme Support:** Toggle between Dark & Light mode seamlessly with saved user preferences.
- 📦 **Resource & Texture Vault:** Dynamic client-side search and category filtering for MCPE packs and shaders.
- 🔫 **Pro Gunsmith Loadouts:** Quick-copy share codes for ranked weapon setups.
- 🎮 **Controls & Claw HUDs:** 4-finger and 6-finger tablet sensitivity code integration.
- 🌐 **Game Servers Hub:** Instant 1-click IP and Bedrock port copy buttons.
- 🎬 **YouTube Content Showcase:** Clean, grid-aligned video links and embedded showcases.
- ⚡ **Interactive Background Elements:** Lightweight interactive gaming fidget floating icons with floating XP floating indicators.
